如何绑定到 Google Gemini / OpenAI ChatGPT？（点击展开 3 步指引）
  1. 在 Gemini（Settings → Connected Apps → Custom apps）或 ChatGPT（Plugins → Add custom MCP server）中新建自定义应用。
  2. 粘贴上方复制的 MCP Server URL；Client ID 与 Client Secret 全部留空（本网关支持 OAuth 2.1 动态注册 DCR）。
  3. 弹出本机授权确认页时，粘贴 Owner Approval Key 点击确认，即可在对话中 @ 调用本机工具。

选择公网接入方式

Cloudflare Quick Tunnel 新手推荐
免服务器、免域名、零成本；自动绕过 Clash/Mihomo Fake-IP。重启后临时地址会变化。
Cloudflare Named Tunnel
免 VPS，绑定你自己的 Cloudflare 固定域名，重启后 URL 永久不变。
自建 Linux VPS（SSH -R）
通过 OpenSSH 反向隧道接入自建 Ubuntu/Debian VPS，适合长期稳定常驻。
仅本机调试模式
仅监听 127.0.0.1，不拉起外部隧道，适合本机联调或外接自定义反代。
